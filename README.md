# 株式会社ユタカエンジニアリング コーポレートサイト

このリポジトリは、株式会社ユタカエンジニアリングの静的コーポレートサイトです。React と Vite を用いたフロントエンドのみの構成であり、バックエンド、データベース、ログイン機能は含みません。ソース一式、更新箇所、画像台帳、公開時の確認事項をこのリポジトリ内にまとめているため、別の制作担当者へ引き継ぐことを前提にしています。

デプロイ環境によっては `client/` をビルド起点として認識するため、同ディレクトリにも独立した `package.json` と `vite.config.ts` を置いています。これはデプロイ互換性のための構成であり、ルートの `package.json` はローカル開発・型チェック・CIのために維持しています。

## ローカル起動と本番ビルド

Node.js 22系と pnpm を用意したうえで、リポジトリ直下で次のコマンドを実行します。

```bash
pnpm install
pnpm dev
```

ブラウザで表示を確認する場合は、開発サーバーの案内するURLにアクセスしてください。本番用の静的ファイルを作成する場合は、次を実行します。

```bash
pnpm check
pnpm build
```

生成結果は `dist/` に出力されます。GitHub Pages、Netlify、Cloudflare Pages、社内ホスティングなど、静的ファイルを配信できるサービスに `dist/` の内容を配置できます。公開作業は、電話番号や会社情報の最終確認後に行ってください。

最終確認では、`pnpm check` と `pnpm build` が正常終了しています。引継ぎ後に依存関係を更新した場合は、同じ2つのコマンドで再確認してください。

| 使用画像の用途・差し替え方法 | `ASSET-REGISTER.md` | 画像URLと代替テキストを確認します。 |
| 事実情報の確認状況 | `CONTENT-UPDATE-GUIDE.md` | 公開前の確認項目を管理します。 |

## デザイン方針

デザインの名称は **Quiet Current** です。SoftBankグループサイトのような、広い余白・大きいビジュアル・短い見出し・整然とした情報階層を参照しています。ただし、同社のロゴ、画像、文章、固有の配色、レイアウトは使用していません。深いチャコール、白、アクセントの Circuit Red（`#C63935`）によって、配電・制御の堅牢性と人の精度を表現しています。詳しい判断基準は `ideas.md` を参照してください。

## 公開前の確認

会社名は **株式会社ユタカエンジニアリング** で統一してください。代表者名、電話番号、FAX番号、所在地、拠点、従業員数、資本金、認証・許認可、営業時間、取引先、画像の掲載許諾は、公開担当者が最新情報を確認してから掲載してください。現状のページは、確認済みの公開情報を基礎として構成していますが、外部公開を前提とした最新性の保証は行いません。

## 追加を推奨するページ

この初期版は、発注・相談につながる基本情報を一つの長いホームページに集約しています。次の段階では、実績紹介、品質・設備紹介、採用情報、お知らせの順で追加すると、営業・採用・信頼形成の効果が高まります。各ページの狙いと必要な素材は `SUGGESTED-EXPANSION.md` に整理しています。
